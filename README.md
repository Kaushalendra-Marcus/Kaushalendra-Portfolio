## Getting Started

**Prerequisites:** Node.js 18+

```bash
# Clone the repository
git clone https://github.com/Kaushalendra-Marcus/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

---

## Project Structure

```
src/
├── app/            # Next.js App Router — pages and layouts
├── components/     # Reusable React components
├── data/           # Projects, experience, and skills data
└── types/          # TypeScript interfaces and types
```

---

## Customization

All content lives in `src/data/`. To update the portfolio with your own information, edit the relevant data files — no changes needed elsewhere.

---

## Deployment

Deployed on Vercel. To deploy your own fork:

1. Push to GitHub
2. Import the repo at [vercel.com](https://vercel.com)
3. Deploy — zero configuration needed
