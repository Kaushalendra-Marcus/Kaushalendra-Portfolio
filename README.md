# Kaushalendra Singh - Portfolio

A modern, performant portfolio website built with Next.js 15, TypeScript, and Tailwind CSS v4.

## Features

- **Interactive UI** – Project modals, animated scroll line with section markers
- **Performance** – 90+ Lighthouse score, optimized images, SSR
- **SEO Optimized** – Semantic HTML, meta tags, sitemap
- **Responsive** – Mobile-first design, works on all devices
- **Resume Download** – One-click PDF access
- **Analytics** – Vercel Analytics integrated

## Tech Stack

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: React Icons (Fa6)
- **Animations**: Framer Motion
- **Analytics**: @vercel/analytics
- **Deployment**: Vercel
